# ADR-0003. Ответ только по контекстам, цитаты проверяются на сервере

**Статус:** принято

## Контекст

Для юридического помощника выдуманная норма опаснее, чем отказ. Языковые модели иногда искажают цитаты, придумывают номера статей и суммы.

## Решение

1. Модель получает только пронумерованные найденные статьи и инструкцию отвечать исключительно по ним.
2. Вывод строго в JSON: `answer`, `citations[{ref, quote}]`, `no_answer`, `confidence`.
3. Сервер не доверяет цитате модели: `_fix_quote` ищет её в нормализованном тексте статьи и возвращает **дословный** фрагмент оригинала и номер части. Если не нашёл — подставляет ближайший по словам абзац.
4. Ссылки на несуществующие контексты удаляются, контексты перенумеровываются.
5. Если не осталось ни одной валидной цитаты, ответ превращается в `no_answer`.
6. В поиск попадают только действующие акты.

## Последствия

- ➕ Каждое утверждение проверяемо: цитата и ссылка на статью на lex.uz.
- ➕ Метрика «выдуманные ссылки» в `eval/run_eval.py` проверяет это автоматически.
- ➖ Иногда система честно отказывается там, где модель «могла бы догадаться». Это осознанный выбор.
