# ADR-0005. Провайдер LLM выбирается переменной окружения

**Статус:** принято

## Контекст

Цены и модели меняются, у провайдера могут быть сбои, а проект должен запускаться и без платного ключа (для разработки и демонстрации).

## Решение

`app/llm.py` прячет провайдера за функциями `search_keywords()` и `answer()`; `rag_api._llm_text()` делает то же для API. Переменная `AI_PROVIDER`:

- `openai` — основной вариант, `gpt-4.1-mini`, JSON-режим `response_format`;
- `claude` — запасной, структурированный вывод через JSON-схему;
- `mock` — без ключа: поиск работает, ответ собирается из лучшей статьи. Включается сам, если ключей нет.

Модели тоже задаются переменными (`OPENAI_MODEL`, `OPENAI_KW_MODEL`, `CLAUDE_MODEL`).

## Последствия

- ➕ Сменить модель или провайдера можно без изменения кода.
- ➕ Сайт и тесты работают без ключа.
- ➖ Два провайдера по-разному поддерживают `temperature` и `seed`, поэтому детерминизм дополнительно обеспечивается кэшем ([ADR-0002](0002-llm-query-rewriting.md)).
