# ADR-0004. Модульный монолит

**Статус:** принято

## Контекст

Есть сайт, RAG API, поиск, слой LLM и конвейер данных. Их можно разнести по микросервисам, но команда — один человек, нагрузка небольшая, а хостинг должен стоить 4–6 $ в месяц.

## Решение

Один процесс FastAPI/Uvicorn со строгими слоями:

- представление: `main.py` (сайт) и `rag_api.py` (API) — только HTTP и сборка ответа;
- данные и поиск: `db.py`, `textnorm.py`, `translit.py` — единственное место, где есть SQL;
- ИИ: `llm.py` — единственное место, где знают про конкретного провайдера.

Offline-конвейер (`build_db.py`, `chunking.py`) отделён от online-части и связан с ней только файлом `laws.db`.

## Последствия

- ➕ Один `Dockerfile`, одна команда запуска, нет сетевых вызовов между своими сервисами.
- ➕ Границы модулей позволяют позже вынести, например, поиск в отдельный сервис без переписывания API.
- ➖ Лимиты запросов хранятся в памяти процесса; для нескольких реплик их нужно вынести в Redis.
